
# osTicket IT Help Desk Home Lab

## Project Overview

This project demonstrates my hands-on practice setting up and managing an IT help desk environment using osTicket on Ubuntu Server in VirtualBox.

## Technologies Used

- Ubuntu Server 24.04 LTS
- VirtualBox
- osTicket 1.18.4
- Apache Web Server
- MySQL
- PHP
- SSH

## Lab Configuration

- Installed and deployed osTicket on Ubuntu Server.
- Configured Apache, PHP and MySQL.
- Created support departments and help topics.
- Configured SLA plans for ticket management.
- Practised ticket assignment, prioritisation, internal notes and customer-facing replies.

## Simulated Support Scenarios

1. Wi-Fi connectivity failure
2. Software installation failure
3. Intermittent internet connectivity
4. Printer not responding

These scenarios are simulated for learning purposes and do not represent professional IT support experience.

## Skills Practised

- Linux server administration fundamentals
- Web application deployment
- Basic database administration
- Help desk ticket management
- Incident documentation
- Customer communication
- Troubleshooting methodology
